# Volume II: Household Capital Class Structures and Comparative Analysis

## Overview

Volume II constitutes the empirical core of the Community Capital Development Project. It systematically classifies households into distinct capital-based class categories, presents comparative analyses of these categories, and develops the Household Capital Development Index for measurement and comparison.

This volume draws upon the theoretical frameworks established in Volume I and provides the analytical foundation for the assessment tools developed in Volume III.
