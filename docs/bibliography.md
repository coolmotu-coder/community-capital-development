# Bibliography

This bibliography lists sources referenced and consulted in the development of the Community Capital Development Project.

## Note on Sources

All references in this project are drawn from documented academic literature, field research, and verified primary sources. Where specific citations are integrated into chapter content, they are listed within each volume's `references.md` page.

The references for Volume 2 are available at [Volume II — References](volume-02/references.md).

## Categories of Sources

Sources consulted in this project span the following categories:

- **Academic journals** in development economics, political economy, sociology, and rural studies
- **International development reports** from multilateral institutions
- **Government publications** and policy documents
- **Field research data** and community-level assessments
- **Household survey datasets**
- **Theoretical literature** on capital, class, and development

## Reference Management

Full reference documentation is maintained in the `research/references/` directory. Researchers interested in conducting a systematic review of sources used in this project should consult this directory.
